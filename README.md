## Dokumentasi Kegiatan Workshop

## 1. Rangkuman Materi

Workshop Day 1 membahas tentang penggunaan AI dalam pengembangan aplikasi serta pengelolaan proyek menggunakan Git dan GitHub.

**A. Prompt Engineering**

Prompt Engineering merupakan cara menyusun instruksi agar AI menghasilkan jawaban yang tepat dan sesuai kebutuhan. Prompt yang baik terdiri dari empat bagian, yaitu Role, Task, Context, dan Format.

**B. Git dan GitHub**

Git adalah sistem untuk mencatat dan mengelola perubahan pada file atau proyek. Sedangkan GitHub merupakan platform online untuk menyimpan repository Git dan memudahkan kolaborasi.

**C. Dasar-Dasar Git**

Peserta mempelajari beberapa perintah dasar Git, seperti `git init`, `git add`, `git commit`, `git push`, dan `git pull` untuk mengelola serta mengunggah perubahan proyek.

**D. Praktik Pengembangan Aplikasi**

Peserta diperkenalkan dengan pembuatan aplikasi Student Task Planner menggunakan bantuan AI. Setelah itu, proyek dikelola menggunakan Git dan diunggah ke GitHub.

## 2. Poin Penting dan Pengetahuan Baru

- Membuat prompt AI dengan struktur Role, Task, Context, dan Format.
- Memahami perbedaan Git dan GitHub.
- Mempelajari perintah dasar Git seperti `init`, `add`, `commit`, dan `push`.
- Mengetahui cara menyimpan proyek ke GitHub.

## 3. Pendapat Pribadi

Menurut saya, workshop ini bermanfaat karena memberikan pengetahuan dasar tentang penggunaan AI, Git, dan GitHub. Materi yang diberikan juga dapat membantu dalam mengembangkan aplikasi dan mengelola proyek ke depannya.
